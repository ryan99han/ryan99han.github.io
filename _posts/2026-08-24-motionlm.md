[MotionLM: Multi-Agent Motion Forecasting as Language Modeling](https://arxiv.org/pdf/2309.16534)

MotionLM represents continuous trajectories as sequences of discrete motion tokens and uses a language modeling task to predict multi-agent motion

---

## Glossary
- Road agent: Anything moving in a traffic environment e.g. cars, pedestrians, cyclists, etc.
- Anchor: Pre-programmed templates of common paths e.g. "turn left" or "go straight" templates
- Post-hoc interaction: Individual agent trajectories are generated (e.g. Car A motion predicted in isolation and Car B motion predicted in isolation) followed by a separate set of rules to resolve independent predictions
- Right-Hand Rule coordinate system:
  - Point your right thumb ($+x$), index finger ($+y$), and middle finger ($+z$) at right angles to each other
  - $+x$ axis: Points forward
  - $-x$ axis: Points backward
  - $+y$ axis: Points left (90° counter-clockwise from forward)
  - $-y$ axis: Points right (90° clockwise from forward)

## Overall
- MotionLM leverages the standard language modeling objective, maximizing the average log probability over sequence tokens
  - Does not require anchors
  - Does not require latent variable optimizations to generate diverse predictions
- MotionLM produces joint distributions over interactive agent futures in a single autoregressive decoding process
  - Bypasses post-hoc interactions
  - Rolls out the future step by step for all agents at the same time, with their interactions emerging naturally as part of the process
- Let $S$ be the input data for a scenario at current time $t = 0$ which may include:
  - Roadgraph elements (e.g. lane lines)
  - Traffic light states
  - Features describing road agents and their recent histories
- The task is to predict the joint agent states $Y_t$ for $N$ agents at future timesteps $t = 1, ..., T$

$$Y_t = \{y_t^1, y_t^2, ... , y_t^N\}$$

- Instead of complete states, these future states are represented as 2D waypoints (i.e. (x, y) coordinates), with $T$ waypoints forming the full ground truth trajectory for an agent

## Joint Probabilistic Rollouts
- In the modeling framework, a predicted action is sampled for each target agent at each future timestamp
- Let $a_t^n$ represent the target action (derived from ground truth waypoints) for the $n$th agent at time $t$
- Let $A_t = \\{a_t^1, a_t^2, ..., a_t^N\\}$ represent the set of target actions for all agents at time $t$

$$p_\theta(A_1, A_2, ... A_T | S) = \prod_{t=1}^T p_\theta(A_t | A_{\lt t}, S)$$

$$p_\theta(A_t | A_{\lt t}, S) = \prod_{n=1}^N p_\theta(a_t^n | A_{\lt t}, S)$$

- The second equation shows we treat agent actions as conditionally independent at time $t$ given the previous actions and scene context
- In real-world driving, the reaction time of human drivers is \~500ms
- The model operates at 2 Hz, meaning it makes a prediction every 500ms, making the gap between timestep $t$ and $t + 1$ exactly 500ms
- Take the following scenario
  - At time $t = 0$ that Agent A brakes
  - Because of the human reaction time, Agent B cannot physically respond for at least 500ms
  - Therefore, whatever Agent B decides to do at $t = 0$ is completely independent of Agent A's braking
  - Agent B is only acting based on the history of the scene up to the point $A_{\lt t}$
  - The model can therefore calculate Agent A's action and Agent B's action at timestep $t$ in parallel, treating them as independent!
  - Without this simplification, modeling multiple interacting agents is incredibly complex

## Training objective
- Maximum likelihood objective over multi-agent action sequences

$$\operatorname*{argmax}_\theta \prod_{t=1}^T p_\theta(A_t | A_{\lt t}, S)$$

- Similar to the training setup of LLMs, "teacher-forcing" is used where previous ground truth tokens are provided at each timestep, NOT the predicted tokens
- In training, each target agent is exposed to the ground truth action sequence prefixes for all target agents prior to the current timestamp
- The model suffers from the same theoretical limitations as general imitation learning frameworks
  - Compounding error: Errors made step-by-step accumulate over time i.e. during inference the model predicts step 1, feeds its own prediction back as input to predict step 2, etc. but if the model makes a small error in step 1, step 2 is even less accurate, and so on
  - Self-delusions: Model learns fake causal relationships because it cannot see every hidden factor that affected the human driver e.g. stopping because of a hidden puddle but a nearby car turned on its blinker so the model concludes that a blinker should trigger braking

## Model
- The model consists of two main networks
  - Encoder processes initial scene elements
  - Trajectory decoder performs cross-attention to scene encodings and self-attention along agent motion tokens

## Scene Encoder
- Process information from several input modalities:
  - Road-graph (lane lines)
  - Traffic light states
  - History of surrounding agents' trajectories
- Early fusion network processes different input modalities together with minimal inductive bias
- Features extracted with respect to each agent's frame of reference
- Input tensors fed to a stack of self-attention layers exchanging information across all past timesteps and agents
- In the first layer, latent queries cross attend to the inputs to reduce the set of vectors being processed to a manageable number

## Joint Trajectory Decoder
- Generates sequences of motion tokens for multiple agents

### Discrete Motion Tokens
- Transform trajectories of continuous waypoints into sequences of discrete tokens
- Allows sampling as a classification task at each timestep (via softmax layer)
- Discrete motion tokens may also naturally hide some precision from the model which could possibly mitigate compounding error effects from imperfect continuous value predictions

### Quantization
- To extract target discrete tokens, the agent's ground truth trajectory is normalized
  - Starting point of the agent at $t = 0$ is $(0, 0)$
  - Trajectory is rotated s.t. the agent's starting direction is the reference heading
- The model learns relative movements $(\Delta x, \Delta y)$ rather than absolute GPS coordinates
- The continuous range of possible movements (from a predefined miniumum to maximum distance) is chopped up into a fixed number of equally sized bins
- Any continuous movement is then rounded to the nearest bin index $[0, \text{num\\_bins} - 1]$
- Therefore, a 2D movement is represented by a pair of bin indices
- A greedy search is used to select the quantized actions which reconstruct the next waypoint coordinates with minimum error
- The delta actions are wrapped with a "Verlet" step which means that a "zero" token means the agent is doing exactly what it did in the previous step
  - Since agent velocities tend to change smoothly between timesteps, this reduces the total vocabulary size, simplifying the training dynamics
- To maintain $T$ instead of $2T$ sequential predictions, the actions are further collapsed into a single integer indexing into their Cartesian product
  - In practice, the model uses $13$ tokens per coordinate with $13^2 = 169$ total discrete tokens available in the vocabulary

### Flattened Agent-Time Self Attention
- The following embeddings are created for each discrete motion token
  - A learned value embedding representing the motion (discrete token ID from $0$ to $168$)
  - A learned positional embedding representing timestep (from $t = 1$ to $t = T$)
  - A learned positional embedding representing agent identity (from Agent $1$ to Agent $N$) are computed for each discrete motion token
- All the motion tokens for every agent are strung together into one long 1D sequence and fed into a single self-attention mechanism in the decoder
  - The sequence length for self attention is therefore $NT$ elements since there are $N$ agents over $T$ timesteps
  - In practice, an 8-second prediction at 2 Hz for 2 agents requires 16 timesteps over 2 agents, yielding 32 tokens

### Ego Agent Reference Frames
- In order to do cross attention on agent-centric feature encodings, the flattened token sequence is repeated for each agent
- In contrast, the scene encodings are centered around each agent's local reference frame at $t = 0$
- Each agent is then treated as the "ego" agent once
  - The first copy of the motion token sequence cross attends to Agent 1's scene encodings
  - The second copy of the motion token sequence cross attends to Agent 2's scene encodings
